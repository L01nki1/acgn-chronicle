Contract · 页面契约

页面遵守的契约
  • 01

    引用对象没有 URL 就不渲染，不灰显、不藏在提示里。

  • 02

    正文在服务端裁剪一次，客户端渲染前再裁剪一次，上限 200 个字符。

  • 03

    每次结果都显示对应快照；缓存键包含快照、问题、筛选、top_k 与配置。

  • 04

    410 表示快照已退役，页面不会自动切到当前快照。

  • 05

    没有检索到片段不是拒答；拒答一定会给出原因。
