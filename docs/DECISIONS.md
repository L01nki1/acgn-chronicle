| 2026-10-28 | **Two corpora, never mixed**: a frozen evaluation snapshot and a rolling daily-digest window | Evaluation needs a corpus that does not move (invariant 2); the product needs a corpus that moves every day. One corpus cannot do both, and keeping them separate is what resolves the conflict instead of trading one requirement against the other | everyone |
| 2026-10-28 | Daily digest dedup window = **14 days**, and it keeps no archive beyond that | Fourteen days is what deduplication needs to recognise the same announcement on its third re-publication, and what makes 'this story is developing' meaningful. History belongs to the evaluation corpus, not to the digest | C, D |
| 2026-10-28 | `gold_evidence` is keyed on **urls**, never on stored chunk ids | A chunk id is only valid inside one (snapshot, chunk_config) pair: A(512/64) and A'(256/0) split the same sentence into different chunks with different ids. A stored id would silently point at nothing after a rebuild or a config change, and every metric built on it would quietly become noise. Chunk ids are resolved per run into `resolved_evidence.json` | D, E, F |
| 2026-10-28 | `retrieval_hit_rate` = hit@k on **any** gold url, with `evidence_recall@k` reported beside it | Requiring every gold url punishes a system that surfaced the authoritative source, and requiring `key_entities` in retrieved text measures the generator's luck rather than retrieval. One number alone can be gamed by returning more chunks, hence the pair | E, D |
| 2026-10-28 | The abstention **calibration set is additional** (20 + 10), disjoint from the 30-item QA set | Selecting the threshold on the items you then report on is leakage: the reported rate is optimistic by construction and nothing in the report reveals it. Disjointness is enforced by `scripts/check_qa.py` | D, E |
| 2026-10-28 | Reproducibility acceptance is **two-tier**: retrieval identical, generation within 1 item of 30 | "Reruns give identical numbers" and "LLMs jitter" cannot both hold for one number. Retrieval is deterministic, so any drift there is a bug; generation gets a tolerance plus a reported spread. Grading is tested separately by re-grading the same saved answers | D, E |
| 2026-10-28 | **D labels all 30 QA items**; E double-labels a fixed 10 for agreement | A set written by six people has six standards, and agreement needs a measurable overlap rather than everyone doing a third of the work. 30 items is 5-6 hours for one annotator | D, E |
| 2026-10-28 | Contract schema exports **wire types only** (`ports.WIRE_MODELS`) | `RetrievedChunk` carries the full article body, yet the schema exposed it and `/retrieve` was documented to return it - so a client could code against a type that must never appear in a response.
